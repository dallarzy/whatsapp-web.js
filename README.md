# AymohBot - WhatsApp Automation Bot 🤖📲

A powerful WhatsApp bot built using [whatsapp-web.js](https://github.com/pedroslopez/whatsapp-web.js), created by **Dallarzy Aymoh**. It supports real-time messaging, auto-replies, and session saving. This project is perfect for anyone looking to learn automation or enhance WhatsApp interaction using Node.js.

---

## ✨ Features

- 🔄 Auto-reply to messages (e.g. `!ping` → `pong`)
- 📦 Built on Node.js + Puppeteer
- 📲 Login using QR code
- 💾 Session saving for persistent login
- 🚀 Easy to deploy on Railway, Render, or VPS
- 🧠 Extendable for AI/chatbot integrations

---

## 🚀 Installation

```bash
git clone https://github.com/dallarzy/aymoh-bot.git
cd aymoh-bot
npm install
node index.js
